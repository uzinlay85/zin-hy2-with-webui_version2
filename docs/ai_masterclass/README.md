# 📚 AI-Assisted Web Development Masterclass

AI (ဉာဏ်ရည်တု) များကို အသုံးပြု၍ ကိုယ်ပိုင် Web App များကို ပရော်ဖက်ရှင်နယ်ကျကျ မည်သို့ရေးသားရမည်ကို လေ့လာနိုင်သော လမ်းညွှန်စာအုပ် ဖြစ်ပါသည်။

## 📖 မာတိကာ (Table of Contents)

1. **[Chapter 1: 🏗️ System Architecture & Databases](01_System_Architecture_and_Databases.md)**
   Web App တစ်ခု၏ ဖွဲ့စည်းပုံ (Frontend, Backend, Database) နှင့် မိမိ App အတွက် မှန်ကန်သော Database ရွေးချယ်ပုံများကို လေ့လာမည်။
   
2. **[Chapter 2: 🔌 API Design & Communication](02_API_Design_and_Communication.md)**
   Frontend နှင့် Backend မည်သို့ ဆက်သွယ်အလုပ်လုပ်သနည်း၊ RESTful API ၏ သဘောတရားများကို လေ့လာမည်။

3. **[Chapter 3: 🛡️ Comprehensive Security (Security-First Mindset)](03_Comprehensive_Security.md)**
   Code ထဲတွင် လုံးဝမပါသင့်သော အရာများ၊ Hacker များ၏ တိုက်ခိုက်မှုများကို ကာကွယ်ရန် လုံခြုံရေး အခြေခံများကို လေ့လာမည်။

4. **[Chapter 4: 🤖 AI Collaboration & Best Practices](04_AI_Collaboration_and_Best_Practices.md)**
   AI ကို Senior Developer တစ်ယောက်ကဲ့သို့ တိကျစွာ ခိုင်းစေနည်း (Prompt Engineering) နှင့် Error များကို ဖြေရှင်းနည်းကို လေ့လာမည်။

5. **[Chapter 5: 🚀 Deployment, Maintenance & Version Control](05_Deployment_and_Maintenance.md)**
   Code များကို Git/GitHub တွင် စနစ်တကျ သိမ်းဆည်းနည်းနှင့် ဆာဗာပေါ်တွင် လုံခြုံစွာ အသက်သွင်းနည်းများကို လေ့လာမည်။
